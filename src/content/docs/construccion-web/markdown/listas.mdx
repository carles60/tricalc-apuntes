### Código

```md
#### Lista no ordenada

- Primer elemento
- Segundo elemento
- Tercer elemento

#### Lista ordenada

1. Primer elemento
2. Segundo elemento
3. Tercer elemento

#### Lista anidada

- Modelado
  - Nudos
  - Barras
  - Láminas
- Cargas
  - Peso propio
  - Sobrecargas
  - Viento

#### Lista de tareas

- [x] Modelo creado
- [x] Hipótesis definidas
- [ ] Combinaciones revisadas
- [ ] Cálculo finalizado
```

---

### Observaciones

- Las listas no ordenadas utilizan `-`, `*` o `+`. Se recomienda utilizar siempre `-` para mantener un estilo uniforme.
- Las listas ordenadas utilizan números seguidos de un punto (`1.`).
- Para crear listas anidadas basta con indentar dos espacios.
- Las listas de tareas utilizan `[ ]` para elementos pendientes y `[x]` para elementos completados.
