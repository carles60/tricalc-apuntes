# Dominio

## Comprar un dominio

Puede adquirirse en cualquier registrador de dominios.

Ejemplos:

- OVH
- IONOS
- Namecheap
- Cloudflare

---

## Asociar el dominio a Netlify

1. Abrir el sitio en Netlify.
2. Entrar en **Site configuration**.
3. Seleccionar **Domains**.
4. Pulsar **Add domain**.
5. Escribir el nombre del dominio.

---

## Configurar el DNS

Modificar los registros DNS según las instrucciones proporcionadas por Netlify.

Normalmente será necesario configurar:

- Registros **A**.
- Registro **CNAME** para `www`.

---

## Comprobar la propagación

La actualización de los servidores DNS puede tardar desde unos minutos hasta varias horas.

---

## Certificado SSL

Netlify genera automáticamente un certificado HTTPS mediante Let's Encrypt.

No requiere configuración adicional.

---

## Redirección WWW

Es recomendable elegir un único dominio principal.

Por ejemplo:

```
https://midominio.com
```

y redirigir automáticamente:

```
https://www.midominio.com
```

hacia él.

---

## Observaciones

- El dominio debe renovarse periódicamente.
- El alojamiento de la web continúa realizándose en Netlify.
- El dominio únicamente proporciona un nombre personalizado para acceder a la web.
