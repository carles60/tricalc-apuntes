# Git

## Comprobar el estado del repositorio

### Código

```bash
git status
```

### Observaciones

Muestra los archivos modificados, añadidos y pendientes de confirmar.

---

## Añadir todos los cambios

### Código

```bash
git add .
```

### Observaciones

Añade todos los archivos modificados al área de preparación (*staging*).

---

## Crear un commit

### Código

```bash
git commit -m "Descripción de los cambios"
```

### Observaciones

Guarda una instantánea de los cambios con un mensaje descriptivo.

---

## Enviar los cambios a GitHub

### Código

```bash
git push
```

### Observaciones

Envía los commits locales al repositorio remoto.

---

## Actualizar el repositorio local

### Código

```bash
git pull
```

### Observaciones

Descarga e integra los cambios existentes en el repositorio remoto.

---

## Ver el historial de commits

### Código

```bash
git log --oneline
```

### Observaciones

Muestra el historial resumido de commits.

---

## Flujo de trabajo habitual

### Código

```bash
git status
git add .
git commit -m "Descripción de los cambios"
git push
```

### Observaciones

Es la secuencia habitual para guardar y publicar cambios.
