### Código de Importación:

- Este código debe situarse justo después del frontmatter

```mdx
import { Image } from 'astro:assets';
import nombre-de-la-imagen from '../../../assets/cargas/nombre-de-la-imagen.png';
```

### Código de Inserción:

- Este código se colocará allá donde aparezca la imagen

```mdx
<Image
  src={nombre-de-la-imagen}
  alt="Descripción de la imagen"
/>
```

### Observaciones
- Las imágenes deben almacenarse dentro de `src/assets`.
- La ruta de importación es relativa al archivo `.mdx`.
- El atributo `alt` es recomendable por accesibilidad.
- `alt` no es un pie de foto ni un texto emergente al pasar el ratón.

### Código completo:

```mdx
import { Image } from 'astro:assets';
import imagenviento from '../../../assets/cargas/imagenviento.png';

<Image
  src={imagenviento}
  alt="Cargas de viento"
/>
```
