# Atajos de teclado

## Abrir una terminal

### Atajo

```text
Ctrl + Ñ
```

### Resultado

Abre o cierra la terminal integrada.

---

## Buscar un archivo

### Atajo

```text
Ctrl + P
```

### Resultado

Permite localizar y abrir rápidamente cualquier archivo del proyecto.

---

## Buscar en todo el proyecto

### Atajo

```text
Ctrl + Shift + F
```

### Resultado

Busca un texto en todos los archivos del proyecto.

---

## Guardar el archivo actual

### Atajo

```text
Ctrl + S
```

### Resultado

Guarda los cambios del archivo activo.

---

## Comentar o descomentar una línea

### Atajo

```text
Ctrl + Ç
```

### Resultado

Añade o elimina el comentario de la línea seleccionada.

---

## Formatear el documento

### Atajo

```text
Shift + Alt + F
```

### Resultado

Formatea automáticamente el documento según las reglas del proyecto.

---

## Paleta de comandos

### Atajo

```text
Ctrl + Shift + P
```

### Resultado

Permite ejecutar cualquier comando disponible en Visual Studio Code.

---

## Copiar una línea

### Atajo

```text
Shift + Alt + ↓
```

### Resultado

Duplica la línea actual debajo de la original.

---

## Mover una línea

### Atajo

```text
Alt + ↑
```

o

```text
Alt + ↓
```

### Resultado

Desplaza la línea actual hacia arriba o hacia abajo.

---

## Eliminar una línea

### Atajo

```text
Ctrl + Shift + K
```

### Resultado

Elimina la línea actual sin necesidad de seleccionarla.

---

## Seleccionar varias coincidencias

### Atajo

```text
Ctrl + D
```

### Resultado

Selecciona la siguiente aparición del texto seleccionado para editar varias a la vez.

---

## Abrir el Explorador

### Atajo

```text
Ctrl + Shift + E
```

### Resultado

Activa el panel del Explorador de archivos.
